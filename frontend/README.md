# AtlasOne — Frontend

Interface web da plataforma AtlasOne, um SaaS voltado à gestão logística e ao acompanhamento de entregas para operações de e-commerce.

## Tecnologias

- React
- TypeScript
- Vite
- React Router
- Lucide React
- Recharts
- CSS

## Requisitos

- Node.js
- npm

## Instalação

```bash
npm install

Desenvolvimento
npm run dev

Build de produção
npm run build

Verificação de código
npm run lint
